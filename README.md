# BlockNova

## Explainable Wallet & Smart Contract Reputation Engine

> **Don't just give a risk score. Show the evidence behind it.**

BlockNova is a deterministic Web3 wallet and smart contract reputation engine that analyzes blockchain activity, security signals, and wallet–contract relationships to identify direct and indirect risk.

Instead of simply returning **"Good" or "Bad"**, BlockNova preserves the evidence behind its decision and produces an explainable, bounded reputation result.

# 🚨 Problem

Users routinely interact with unknown wallets and smart contracts without knowing their previous behavior or hidden risk exposure.

A wallet or contract may have:

- Direct malicious activity
- Suspicious transaction relationships
- Unlimited token allowances
- Privileged contract permissions
- Abnormal transaction behavior
- Indirect exposure through connected addresses

A simple reputation score is not enough.

Users need to know:

> **Why was this address flagged?**

And applications need a way to work with reputation programmatically.

---
